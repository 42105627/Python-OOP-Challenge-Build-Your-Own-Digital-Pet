🐶 Digital Pet - Python OOP Challenge
📌 Project Overview
Welcome to the Digital Pet Project, where you create a virtual pet using Python’s Object-Oriented Programming (OOP) concepts! This project reinforces the use of classes, attributes, methods, and constructors to simulate an interactive pet that can eat, sleep, play, and learn tricks.

🎯 Objective
Create a Dog class with the following features:

Attributes:

name - pet’s name

hunger - (0 = full, 10 = very hungry)

energy - (0 = tired, 10 = fully rested)

happiness - (scale from 0 to 10)

tricks - list of learned tricks

Methods:

eat() - Reduces hunger and increases happiness

sleep() - Restores energy

play() - Uses energy but makes the pet happier

train(trick) - Teaches the pet new tricks

show_tricks() - Displays learned tricks

get_status() - Prints the pet’s current condition
